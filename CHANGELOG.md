## [Unreleased] - 2026-11-10

### Added
- `LICENSE` (GPL-3.0), Python `.gitignore` and `README.md` with setup instructions and placeholders.
- `pyproject.toml` with placeholder project metadata, keywords, classifiers, and `ruff` (including isort rules) and `mypy` configuration.
- `.pre-commit-config.yaml` with `pre-commit-hooks`, `ruff` and `mypy` hooks.
- AppImage recipe in `AppImage/Recipe` (entrypoint, desktop entry, AppStream metadata, icon), its `AppImage/README.md` and `docs/python-appimage.png`.
- `*.AppImage` rule in `.gitignore`.
- README sections: template attribution, title, 'Features', local CD (AppImage) and a commented-out 'Troubleshooting'.
- Default pull request template `.github/pull_request_template.md` and `.github/PULL_REQUEST_TEMPLATE/Default.md`.
- `.github/CODEOWNERS` and its sample `.github/CODEOWNERS_TEMPLATE/CODEOWNERS`.
- `CHANGELOG.md` and its template `.github/CHANGELOG_TEMPLATE/CHANGELOG.md`, based on Keep a Changelog.
- `TO-DO.md`.
- Compatibility with 'a-skills'.
